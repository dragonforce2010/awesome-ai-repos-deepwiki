# Remote State Machine Guardrail

将 [docs/general/remote-surface-state-machine.md](../../../docs/general/remote-surface-state-machine.md) 视为当前远程界面表现的规范参考。

当改动触及远程界面状态机逻辑载体时，触发此技能，即使预期的产品表现“不应该改变”。

典型触发词：
- attach / detach / `/use` / `/follow` / `/new` 状态谓词或转换逻辑
- 选择线程 / 绑定实例 / 输入路由决策
- 队列 / 分发 / 暂停接管门禁逻辑
- 无头启动 / 恢复 / 取消 / 超时 / 恢复推进逻辑
- 请求捕获 / prompt 门禁 / 模态门禁 / 暂存输入进出逻辑
- 命令可用性矩阵逻辑

对于纯文案、样式、日志、测试或未改变这些逻辑载体的重构，不要触发此技能。

## 工作流

1. 阅读规范状态机文档和改动触及的代码路径。
2. 更新文档以匹配当前实现。
3. 审计改动后的表现，排查用户死胡同转换：
   - 界面看起来已 attach 或已选择，但文本/图像/请求输入仍无法进行
   - 阻塞状态没有可见的逃生舱口
   - 过期卡片或过期模态状态仍能拦截输入
   - 本地与远程仲裁可能永久暂停
   - detach 或放弃可能永久锁死界面
4. 如果审计发现 bug 级问题，在提交前修复它，添加或更新测试，然后重新运行一次此审计流。
5. 如果残留的问题是产品权衡而非 bug，将其追加到规范文档的 `## 待讨论取舍` 下。

## 验证基线

1. 针对涉及的状态机路径运行特定测试。
2. 如果新状态图中仍包含 attach/use 成功但用户没有有效下一步动作的路径，不得提交。
